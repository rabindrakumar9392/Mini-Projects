# 🎮 Legends Hub

An interactive web project showcasing the lives and achievements of 20 global legends through a clean and engaging interface.

## ✨ Features

- 🌍 Profiles of 20 global legends
- 🖼️ Interactive legend cards
- 📖 Detailed biography information
- ⚡ Dynamic content using JavaScript
- 📱 Responsive interface
- 🎨 Clean and modern UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
