# 🛒 E-Commerce Website

A frontend e-commerce web application built using HTML, CSS, and JavaScript.

## ✨ Features

- 🛍️ Product browsing
- 🛒 Shopping cart functionality
- 💰 Product pricing
- ⚡ JavaScript-based interactions
- 📱 Responsive user interface
- 🎨 Clean and modern design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was built to practice frontend development, JavaScript, DOM manipulation, user interactions, and building a real-world shopping interface.

- Online payment
