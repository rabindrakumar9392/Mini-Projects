
# 🎬 Movie Web Application

A frontend movie web application built to practice JavaScript, DOM manipulation, user interactions, and multi-page website development.

## ✨ Features

- 🎬 Movie browsing interface
- 🔎 Movie details and view-more page
- 🛒 Cart functionality
- 🔐 Login page
- 📝 Registration page
- 📱 Responsive frontend interface
- ⚡ JavaScript-based DOM interactions
- 🧭 Multi-page navigation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
