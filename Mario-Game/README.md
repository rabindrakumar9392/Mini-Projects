# 🎮 Mario Game

A small browser-based Mario-inspired game built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎮 Player movement
- 🏃 Keyboard controls
- 🧱 Game obstacles
- 💥 Collision interactions
- ⚡ JavaScript-based game logic
- 📱 Browser-based gameplay

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was built to practice JavaScript logic, keyboard events, DOM manipulation, animations, and interactive browser game development.

## 🚀 Future Improvements

- Multiple levels
- Score system
- Sound effects
- More enemies and obstacles
- Better animations
- Mobile controls
