# 💈 HairCutting — Home Haircut Service

A simple frontend web application for booking professional haircut services at your doorstep.

## ✨ Features

- 💇 Multiple haircut styles
- 💰 Service pricing
- 📅 Quick booking form
- 📱 Responsive interface
- 💬 WhatsApp booking integration
- ⚡ Dynamic haircut cards using JavaScript

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
